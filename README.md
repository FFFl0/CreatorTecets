# CreatorTecets

Веб-приложение для автоматического формирования экзаменационных билетов по шаблону Word.

## Возможности

- **Шаблон билета** — по умолчанию используется приложенный шаблон ГБПОУ КМП
  (`app/templates/default_template.docx`). Можно загрузить свой `.docx`.
  Оформление (шапка-таблица, стили, шрифты, поля страницы, колонтитулы) сохраняется полностью.
- **Данные билета** — поля вида «Группа: АТ-224», «Семестр: 4», «Разработчик: …» (в том числе в колонтитулах) находятся в шаблоне автоматически
  и редактируются прямо в интерфейсе.
- **Параметры** — количество билетов, теоретических вопросов и практических заданий в каждом билете;
  распределение случайно или по порядку; режим повторов при нехватке вопросов.
- **Ввод вопросов** — вставка текстом (один вопрос на строку, нумерация «1.», «2)», «•» удаляется сама)
  или загрузка файла `.txt`, `.docx`, `.csv` (кнопкой или перетаскиванием).
- **Проверка** — хватает ли вопросов для всех билетов, сколько не хватает, сколько билетов можно
  сделать без повторов, поиск дубликатов, наличие мест под вопросы в шаблоне. Экспорт блокируется,
  пока есть ошибки.
- **Предварительный просмотр** — билеты в виде страниц A4, сводная таблица и точный PDF-просмотр.
  Любой вопрос в билете можно заменить вручную (клик по вопросу).
- **Экспорт** — один файл Word (`.docx`) или PDF со всеми билетами, каждый билет — с новой страницы.
- **Библиотека шаблонов** — пользователь может по своему желанию отправить свой шаблон на сайт
  (с согласием на публикацию). Администратор проверяет его во вкладке «Модерация» личного кабинета
  (может открыть в редакторе, поправить название и описание), публикует или отклоняет с комментарием.
  Опубликованные шаблоны появляются в списке «Шаблон из библиотеки сайта» у всех пользователей.
  Автор видит статус во вкладке «Мои шаблоны».
- **Личный кабинет** — регистрация по почте и паролю: проверка полей при вводе, индикатор надёжности
  пароля, подтверждение пароля, кнопка «показать пароль», предупреждение о Caps Lock, «Запомнить меня».
  В профиле можно изменить имя и пароль (вход на других устройствах сбрасывается) или удалить аккаунт. Наборы билетов (параметры, списки вопросов,
  готовые билеты с ручными заменами, свой шаблон) сохраняются кнопкой «Сохранить», а после входа —
  автоматически при каждом скачивании. В кабинете наборы можно открыть, скачать заново в .docx/.pdf,
  переименовать и удалить.

## Запуск

**Windows:** дважды щёлкните `start.bat` — он установит зависимости, запустит сервер и откроет браузер.
Нужен Python 3.10+ (при установке отметьте «Add python.exe to PATH»), для PDF — LibreOffice.
Вручную: `py -m pip install -r requirements.txt`, затем `py -m uvicorn app.main:app`.

**Linux / macOS:**

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
# открыть http://localhost:8000
```

Для экспорта в PDF на сервере должен быть установлен LibreOffice (`soffice`).
Путь можно задать переменной `SOFFICE_PATH`.

Через Docker (LibreOffice и шрифты уже внутри):

```bash
docker build -t creatortecets .
docker run -p 8000:8000 creatortecets
```

## Хранение данных

Пользователи и наборы билетов хранятся в SQLite: по умолчанию `data/creatortecets.db`,
путь можно изменить переменной `DB_PATH`. Пароли хранятся в виде хеша (scrypt), вход — через
cookie-сессию на 30 дней. В Docker Compose база лежит в томе `creatortecets-data`.
Для резервной копии достаточно скопировать файл базы.

**Администратор** (модерация шаблонов) задаётся переменной `ADMIN_EMAILS` — почты через запятую.
Если она не задана, администратором считается первый зарегистрированный пользователь, поэтому
на новом сервере зарегистрируйтесь первым или задайте `ADMIN_EMAILS`.

## Cookie и политика конфиденциальности

- При первом визите показывается баннер cookie: «Принять все» или «Только необходимые».
  Метрика и реклама Яндекса загружаются **только** после «Принять все». Изменить выбор —
  ссылка «Настройки cookie» в подвале.
- Страница `/privacy.html` — Политика конфиденциальности (152-ФЗ). Укажите оператора и почту
  в `/opt/creatortecets/.env`, иначе на странице будут подсвеченные заглушки:
  ```
  SITE_OPERATOR="Иванов Иван Иванович"
  SITE_CONTACT_EMAIL="pd@example.ru"
  ```
- При регистрации обязательна галочка согласия на обработку персональных данных;
  дата согласия сохраняется в базе.

## Реклама (Рекламная сеть Яндекса) и Метрика

Реклама выключена, пока не заданы идентификаторы блоков. Места под рекламу: под настройками слева
и внизу страницы. В билеты и скачиваемые документы реклама не попадает, при печати и в режиме
«Развернуть» скрывается.

1. Зарегистрируйтесь в РСЯ (partner.yandex.ru), добавьте сайт (нужен домен) и дождитесь модерации.
2. Создайте два RTB-блока («Адаптивный»), скопируйте их идентификаторы вида `R-A-1234567-1`.
3. Если РСЯ попросит, создайте счётчик Яндекс Метрики (metrika.yandex.ru) и возьмите его номер.
4. На сервере добавьте в `/opt/creatortecets/.env`:
   ```
   YANDEX_RTB_SIDEBAR=R-A-1234567-1
   YANDEX_RTB_BOTTOM=R-A-1234567-2
   YANDEX_METRIKA_ID=12345678
   ```
   и выполните `sudo bash /opt/creatortecets/deploy/update.sh`.

## Требования к своему шаблону

Шаблон — документ Word с **одним** билетом:

| Что | Пример в шаблоне | Что делает приложение |
|---|---|---|
| Номер билета | `Экзаменационный билет № 1` | подставляет номер |
| Теоретический вопрос | абзац `Вопрос1.` | клонирует абзац нужное число раз с тем же оформлением |
| Практическое задание | абзац `Практическое задание1.` (или `Задача1.`, `Задание1.`) | то же |
| Поля | `Группа: АТ-224`, `Разработчик: Иванов И.И./____` (и в колонтитулах) | значение можно изменить; линия для подписи сохраняется |

Метка вопроса сохраняет начертание из шаблона (например, жирный курсив с подчёркиванием),
текст вопроса пишется тем же шрифтом обычным начертанием.

## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/api/template/inspect` | анализ шаблона (`template` — файл, необязательно) |
| `GET` | `/api/template/default` | скачать стандартный шаблон |
| `POST` | `/api/questions/parse` | извлечь вопросы из файла (`file`) |
| `POST` | `/api/auth/register`, `/api/auth/login`, `/api/auth/logout` | регистрация, вход, выход |
| `GET` | `/api/auth/me` | текущий пользователь |
| `PATCH` | `/api/auth/profile` | изменить имя |
| `POST` | `/api/auth/password`, `/api/auth/delete` | сменить пароль / удалить аккаунт |
| `GET` / `POST` | `/api/sets` | список / сохранение набора (`payload`, `template`) |
| `GET` / `PUT` / `PATCH` / `DELETE` | `/api/sets/{id}` | открыть / обновить / переименовать / удалить |
| `GET` | `/api/sets/{id}/export?format=docx\|pdf` | скачать сохранённый набор |
| `POST` | `/api/export` | `payload` (JSON с билетами), `format` = `docx`/`pdf`, `template` (необязательно) |

Пример `payload`:

```json
{
  "filename": "Билеты АТ-224",
  "fields": {"Группа": "АТ-224", "Семестр": "4"},
  "tickets": [{"number": 1, "theory": ["…", "…"], "practice": ["…"]}]
}
```

## Развёртывание на сервере (VPS)

Подойдёт недорогой VPS с Ubuntu 22.04/24.04, 1 ядром и 1–2 ГБ памяти.
Подключитесь к серверу по SSH и выполните одну команду:

```bash
# без домена — сайт будет доступен по http://<IP сервера>:8000
curl -fsSL https://raw.githubusercontent.com/FFFl0/CreatorTecets/ccr-cc297434-iob7x1/deploy/setup.sh | sudo bash

# с доменом и HTTPS (сначала направьте A-запись домена на IP сервера)
curl -fsSL https://raw.githubusercontent.com/FFFl0/CreatorTecets/ccr-cc297434-iob7x1/deploy/setup.sh | sudo DOMAIN=tickets.example.ru bash
```

Скрипт установит Docker, при необходимости создаст файл подкачки, соберёт и запустит приложение
(автозапуск после перезагрузки), а с доменом — получит бесплатный сертификат HTTPS через Caddy.
Ежедневно делается резервная копия базы в `/opt/creatortecets/backups` (хранится 14 дней).

Если репозиторий приватный, склонируйте его вручную в `/opt/creatortecets` (с токеном GitHub)
и запустите `sudo bash /opt/creatortecets/deploy/setup.sh`.

Обновление до новой версии: `sudo bash /opt/creatortecets/deploy/update.sh`.
